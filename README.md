## Abstract

Underwater 3D reconstruction inherently suffers from the **representation mismatch** between continuous optical media and discrete Gaussian primitives. PureSeaGS resolves this with a physics-aware decoupled framework featuring the **Anisotropic Medium Field (AMF)**, achieving state-of-the-art novel view synthesis while preserving real-time rendering.
